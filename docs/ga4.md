# GA4（Google アナリティクス）の設定手順

対象：https://www.hiyori-houkan.com
作業するアカウント：**unique.hiyori@gmail.com**（シークレットウィンドウでこのアカウントだけでログインすると迷わない）

サイト側の準備は済んでいる。Google 側で「測定ID」（`G-` で始まる番号）を発行し、Vercel に登録すれば動き出す。
GA4 は**本番サイトだけ**で動く（確認用ページのテストは数字に混ざらない）。

---

## 1. GA4 のアカウントとプロパティを作る

1. 次のページを開き、unique.hiyori@gmail.com でログイン

```
https://analytics.google.com/
```

2. 「測定を開始」を押す
3. **アカウントの作成**
   - アカウント名：

```
株式会社unique
```

   - 「アカウントのデータ共有設定」のチェックはそのままでよい →「次へ」
4. **プロパティの作成**
   - プロパティ名：

```
訪問看護ステーション陽和 HP
```

   - レポートのタイムゾーン：**日本**
   - 通貨：**日本円（JPY）**
   - 「次へ」
5. **ビジネスの説明**
   - 業種：**健康・フィットネス**（なければ「その他」）
   - ビジネスの規模：**小規模**
   - 「次へ」
6. **ビジネス目標**：「見込み顧客の獲得」にチェック →「作成」
7. 利用規約の画面：国を「**日本**」にして、2つの同意にチェック →「同意する」

## 2. ウェブサイトを登録して「測定ID」を取る

1. 「データの収集を開始する」で「**ウェブ**」を選ぶ
2. ウェブサイトの URL：左の欄は `https://` のまま、右の欄に次を入力

```
www.hiyori-houkan.com
```

3. ストリーム名：

```
陽和HP
```

4. 「拡張計測機能」はオンのまま →「作成して続行」（または「ストリームを作成」）
5. 「Google タグの設置手順」という画面が出たら、**右上の × で閉じてよい**（サイト側は準備済みのため）
6. 「ウェブストリームの詳細」画面の右上にある「**測定 ID**」（`G-XXXXXXXXXX`）の横のコピーのアイコンを押してコピーする

## 3. Vercel に測定IDを登録する

1. Vercel のプロジェクト →「Settings」→「Environment Variables」→ 追加
2. Key（名前）：

```
NEXT_PUBLIC_GA_ID
```

3. Value（値）：2でコピーした `G-` で始まる測定ID を貼り付け
4. Environments は **Production だけ**にチェック →「Save」
5. 「Deployments」→ いちばん上の Production の行の「…」→「Redeploy」
   - 「Use existing Build Cache」のチェックを**外してから** Redeploy

## 4. 動いているか確認する

1. GA4 の左メニュー「レポート」→「リアルタイム」を開いておく
2. 別のタブ（スマホでもよい）で本番サイトを開き、いくつかページを移動する
3. 1〜2分以内に「過去 30 分間のユーザー」が 1 以上になれば OK

---

## 5. やっておくとよい設定（どれも数分）

### 5-1. データの保存期間を長くする
初期は2か月で消える。前年と比べられるよう14か月にする。
1. 左下の歯車「管理」→「データの収集と修正」→「データ保持」
2. 「イベントデータの保持」を **14 か月** →「保存」

### 5-2. フォーム送信を「成果」として数える
お問い合わせ・エントリーの完了ページが表示された回数を、成果（キーイベント）として数える。

1. 「管理」→「データの表示」→「イベント」→ 右上「イベントを作成」→「作成」
2. 1つ目（お問い合わせ）
   - カスタム イベント名：

```
contact_complete
```

   - 一致する条件：
     - 1行目：パラメータ `event_name`／演算子「次と等しい」／値 `page_view`
     - 「条件を追加」で2行目：パラメータ `page_location`／演算子「次を含む」／値：

```
/contact/thanks
```

   - 「作成」
3. 2つ目（採用エントリー）も同じように作る。イベント名と値だけ変える

```
entry_complete
```

```
/entry/thanks
```

4. 「管理」→「データの表示」→「主要なイベント」→「新しい主要なイベント」で、`contact_complete` と `entry_complete` をそれぞれ登録する
   - ※ 実際にフォームが送信されるまで一覧に出ないことがあるので、その場合はこの手順で名前を直接登録する

### 5-3. Search Console とつなぐ
GA4 の中で「どんな言葉で検索されて来たか」が見られるようになる。
1. 「管理」→「サービスとのリンク」→「Search Console のリンク」→「リンク」
2. 「アカウントを選択」→ `hiyori-houkan.com` にチェック →「確認」→「次へ」
3. ウェブストリーム「陽和HP」を選ぶ →「次へ」→「送信」

### 5-4. X-EDGE も見られるようにする（任意）
1. 「管理」→「アカウントのアクセス管理」→ 右上「＋」→「ユーザーを追加」
2. X-EDGE のメールアドレス、役割「**編集者**」→「追加」

---

## 6. 終わったら
Claude に「GA4できた」と伝える → 本番サイトで正しく読み込まれているかを確認する。

## メモ
- プライバシーポリシーの「アクセス解析について」に、Google アナリティクスの利用・Cookie・無効にする方法を記載済み（Google の規約で必要なため）
- 事業所の中のパソコンからのアクセスを数字から除きたい場合は、「管理」→「データストリーム」→「陽和HP」→「タグ設定を行う」→「内部トラフィックの定義」で事業所の IP アドレスを登録する

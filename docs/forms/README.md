# フォームの受付設定（Googleスプレッドシート連動）

ホームページのお問い合わせ・採用エントリーは、送信されると次のように動きます。

```
サイトのフォーム（入力チェック・迷惑送信対策）
  → /api/contact・/api/entry
  → Google Apps Script（このフォルダの apps-script.gs）
      ① スプレッドシートに1行保存（シート「お問い合わせ」「採用エントリー」）
      ② 事業所（unique.hiyori@gmail.com）へ通知メール
      ③ 入力者へ自動返信（メールアドレスがあるときだけ）
```

メールは **unique.hiyori@gmail.com から送られます**。自動返信に返信された場合も、このアドレスに届きます。

## 設定手順（unique.hiyori@gmail.com でログインして行う）

### 1. スプレッドシートを作る
1. Googleドライブで新しいスプレッドシートを作成し、名前を「陽和HP フォーム受付」にする
2. シートは作らなくてよい（初回の送信時に自動で作られる）

### 2. プログラムを貼り付ける
1. スプレッドシートのメニュー「拡張機能」→「Apps Script」
2. 最初から入っている内容をすべて消し、`apps-script.gs` の中身を貼り付けて保存
3. 左の歯車（プロジェクトの設定）→ 一番下「スクリプト プロパティ」→「プロパティを追加」
   - プロパティ：`SECRET`
   - 値：推測されにくい長い文字列（例：パスワード生成ツールで作った40文字程度の英数字）
   - ※ この値は手順4でも使うので控えておく
4. エディタに戻り、上の関数選択で `testSetup` を選んで「実行」
   - 初回は「承認が必要です」と出るので、アカウントを選び「詳細」→「（安全ではないページ）に移動」→「許可」
   - 通知先にテストメールが届き、スプレッドシートに「テスト」シートができれば OK（「テスト」シートは消してよい）

### 3. 外から受け付けられるように公開する
1. 右上「デプロイ」→「新しいデプロイ」→ 種類の歯車から「ウェブアプリ」
2. 次のアカウントとして実行：**自分**／アクセスできるユーザー：**全員**
3. 「デプロイ」を押し、表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）を控える
   - 「全員」にしても、合言葉（SECRET）が合わない送信は断るようになっている

### 4. Vercel に登録する
Vercel のプロジェクト →「Settings」→「Environment Variables」に追加（Production と Preview の両方）。

| 名前 | 値 |
|---|---|
| `GOOGLE_SCRIPT_URL` | 手順3のURL |
| `GOOGLE_SCRIPT_SECRET` | 手順2で決めた SECRET と同じ文字列 |

登録後、「Deployments」から最新のものを **Redeploy** する（再公開しないと反映されない）。

### 5. 送信テスト
- `/contact` と `/entry` から1回ずつ送信（同じ回線からは1分空ける）
- スプレッドシートに行が増え、通知メールと自動返信の両方が届くことを確認
- 初回は迷惑メールフォルダに入ることがあるので確認する

## 運用メモ
- スプレッドシートの「対応状況」列は、返信したら「対応済み」などに書き換えて使う
- Gmail（無料アカウント）から送れるメールは **1日100通まで**。通常の問い合わせ数なら問題ない
- `apps-script.gs` を書き換えたときは「デプロイ」→「デプロイを管理」→ 鉛筆 →「バージョン：新バージョン」で更新する（URLは変わらない）。「新しいデプロイ」にするとURLが変わるので、Vercel 側も直す必要がある
- 通知先を変えたいときは `apps-script.gs` の `NOTIFY_TO` を書き換えて、上のとおり更新する

# Google 検索・AI検索への登録手順

対象：https://www.hiyori-houkan.com
作業するアカウント：**unique.hiyori@gmail.com**（事業所のものとして持っておくため。シークレットウィンドウでこのアカウントだけでログインすると迷わない）

所要時間：30分ほど（確認待ちの時間は別）

---

## 1. Google Search Console（Google検索への登録）

Search Console は「Google にサイトの存在を伝え、検索でどう表示されているかを見る」ための無料の管理画面。

### 1-1. 管理画面を開く

1. シークレットウィンドウ（Ctrl + Shift + N／Mac は ⌘ + Shift + N）を開く
2. 次のページを開き、unique.hiyori@gmail.com でログインする

```
https://search.google.com/search-console
```

3. 「Google Search Console へようこそ」という画面が出る
   - すでに使ったことがある場合は、左上のサイト名の欄 →「プロパティを追加」

### 1-2. ドメインを登録する

画面に「ドメイン」（左）と「URL プレフィックス」（右）の2つの枠がある。**左の「ドメイン」**を使う（www あり・なしの両方をまとめて登録できる）。

1. 左の「ドメイン」の入力欄に次を入れる

```
hiyori-houkan.com
```

2. 「続行」を押す
3. 「DNS レコードでのドメイン所有権の確認」という画面になる
   - 手順の1番「レコードタイプ」は TXT のまま
   - 2番の欄に `google-site-verification=` で始まる長い文字列が出ている → 右の「コピー」を押す
   - **この画面は閉じずに開いたままにしておく**

### 1-3. Vercel に確認用の値を登録する

「このドメインの持ち主です」と Google に証明するための作業。

1. 新しいタブで Vercel を開く

```
https://vercel.com/dashboard
```

2. **プロジェクトを開く前の画面**で、上のメニューの「Domains」を押す
   - 見当たらない場合：左上のチーム名（tsuchiyamakoushi10s-projects）を押してから「Domains」
3. 一覧の `hiyori-houkan.com` を押す
4. 下のほうの「DNS Records」で、次のとおり入力する

| 欄 | 入力するもの |
|---|---|
| Name | **空欄のまま**（何も入れない） |
| Type | `TXT` を選ぶ |
| Value | 1-2でコピーした `google-site-verification=……` を貼り付け（Ctrl + V） |
| TTL | そのまま |
| Comment | 空欄でよい |

5. 「Add」を押す
6. 一覧に TXT の行が1つ増えたことを確認する

### 1-4. 確認ボタンを押す

1. Search Console のタブに戻る
2. 右下の「確認」を押す
3. 「所有権を証明しました」と出れば成功 →「プロパティに移動」
   - 「所有権を確認できませんでした」と出たら、**15分〜1時間ほど待って**からもう一度「確認」を押す（Vercel の設定が世の中に伝わるのに時間がかかるため。失敗しても何も壊れない）

### 1-5. サイトの一覧（sitemap）を送る

Google に「このサイトにはこのページがあります」と一覧を渡す作業。

1. 左のメニュー「インデックス作成」の中の「サイトマップ」
2. 上の「新しいサイトマップの追加」の欄に、次を**まるごと**貼り付ける

```
https://www.hiyori-houkan.com/sitemap.xml
```

   - 欄の左側にすでに `https://hiyori-houkan.com/` などが表示されている場合は、`sitemap.xml` の部分だけ入れればよい

3. 「送信」
4. 下の「送信されたサイトマップ」に行が出て、ステータスが「成功しました」になれば OK
   - 「取得できませんでした」と出ても、数時間〜1日で「成功しました」に変わることが多い。1日たっても変わらなければ Claude に伝える

### 1-6. 大事なページを先に見てもらう（任意だがおすすめ）

sitemap だけでも数日〜数週間で検索に載るが、主要ページは直接お願いすると早い。

1. 画面いちばん上の検索欄（「〜内のすべての URL を検査」）に、次の1つ目を貼り付けて Enter

```
https://www.hiyori-houkan.com/
```

2. 結果が出たら「**インデックス登録をリクエスト**」を押す（1〜2分かかる）
3. 「インデックス登録をリクエスト済み」と出たら閉じる
4. 残りのページも同じようにする（1日にできる回数に上限があるので、この5つで十分）

```
https://www.hiyori-houkan.com/service
```

```
https://www.hiyori-houkan.com/recruit
```

```
https://www.hiyori-houkan.com/about
```

```
https://www.hiyori-houkan.com/contact
```

### 1-7. X-EDGE も見られるようにする（任意）

1. 左のメニューいちばん下「設定」→「ユーザーと権限」
2. 右上「ユーザーを追加」→ X-EDGE のメールアドレスを入れる → 権限「フル」→「追加」

### 1-8. 1〜2週間後に見るところ

- 左メニュー「ページ」：「登録済み」の数が増えていれば検索に載っている
- 左メニュー「拡張」の中の「求人情報」「パンくずリスト」「よくある質問」など：エラーが出ていないか
  - 求人情報は「掲載日（2026-11-01）が未来」という注意が開設日前だけ出ることがあるが、11月1日を過ぎれば消える
- 左メニュー「検索パフォーマンス」：どんな言葉で検索されたか

## 2. Bing Webmaster Tools（ChatGPT・Copilot 向け）

ChatGPT の検索機能や Microsoft の Copilot は、Bing（Microsoft の検索）の情報を使っている。Search Console の登録が終わっていれば、**取り込むだけ**で済む。

1. 次のページを開く

```
https://www.bing.com/webmasters
```

2. 「Sign in」→「Google」を選び、unique.hiyori@gmail.com でログイン
3. 「Import your sites from GSC」（Google Search Console からインポート）の「Import」を押す
4. 許可を求められたら「許可」→ `hiyori-houkan.com` にチェック →「Import」
5. sitemap も一緒に取り込まれる。これで完了

## 4. ホームページ側のAI向け対策（設定済み）

AIの回答に正しく引用されるよう、サイト側で次を済ませてある。追加の作業は不要。

| 対策 | 内容 |
|---|---|
| AI向けの要約 | `https://www.hiyori-houkan.com/llms.txt` に、事業所情報・対応内容・利用の流れ・採用情報を文章でまとめている（原稿から自動で作る） |
| AIの巡回を許可 | 検索エンジンや AI の巡回を止めていない（お礼ページ・送信処理だけ除外） |
| 事業所の情報 | 名前・住所・電話・FAX・営業時間・対応エリア・対応できる療養・地図・運営会社を、機械が読める形で全ページに入れている |
| サイト名 | 検索結果に「訪問看護ステーション陽和（ひより）」と正しく出るよう、トップに情報を入れている |
| よくある質問 | 事業内容・採用情報の質問と答えを、機械が読める形で入れている |
| 求人 | 看護師／PT・OT の2件を、Google しごと検索に載る形で入れている |
| パンくず | 各ページの位置づけを入れている |
| 正式なURL | 全ページで「正式なアドレスはこれ」と指定している（古いアドレス・www なしからは自動で転送） |

### 今後、AIに引用されやすくするためにできること
- お知らせを定期的に足す（開設、見学会、採用、季節のことなど）。更新があるサイトは信頼されやすい
- 2・3人目のスタッフ紹介がそろったら追加する
- 【要確認】の項目（指定事業所番号など）が決まったら、原稿に反映する
